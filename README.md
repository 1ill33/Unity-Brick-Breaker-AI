# Unity Brick Breaker AI

Unity brick breaker with trained AI opponents, developed as an Oregon State University class team project in Summer 2024.

## Open the project

Add the `ML-Breakout-Su24` folder to Unity Hub and open it with **Unity 2022.3.36f1**. The project uses **Unity ML-Agents 2.0.1**. Start with `Assets/Scenes/Menu.unity`.

The Unity project folder includes source code, artwork, prefabs, scenes, package manifests, project settings, trained ONNX models, training configuration, and saved training results. See the [original project README](ML-Breakout-Su24/README.md) for training setup details.

## Christopher O'Neill's contribution

- Built most of the base game in Unity using C#.
- Contributed to AI training and reward/penalty design for ball hits, brick breaks, power-ups, and missed balls.
- Helped refine rewards to address unintended AI behavior.
- Collaborated through GitHub and wrote tests to help with debugging.

The team produced three AI difficulty levels for split-screen play. This was a collaborative project, and the repository contains work by the project team.

## Project origin

This repository is a snapshot of Christopher's local project copy. The original team repository is [ML-Breakout-OSU/ML-Breakout-Su24](https://github.com/ML-Breakout-OSU/ML-Breakout-Su24).

Unity-generated caches, editor build files, and the duplicate ZIP archive are omitted. Unity regenerates its cache folders when the project opens.
